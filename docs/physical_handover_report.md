# 真实物理双臂交接正式报告

## 1. 结论

`Essay2608-Bimanual-Physical-Handover-v0` 已经实现了不依赖几何 carrier 的真实交接闭环，但当前脚本专家尚未达到稳定验收线。

预注册的 20 个未见种子得到 `6/20` 成功，成功率为 `30.0%`，Wilson 95% 区间为 `[14.5%, 51.9%]`。该结果低于协议规定的 `18/20` 科学验收线和 `20/20` 新数据采集门槛。因此：

- 不创建 `data/handover_physical/v1`；
- 不开始完整双臂学习策略训练；
- 不能声称当前物理专家已经鲁棒；
- 可以声称真实物理交接链路和成功样本中的关系转移已经被实现并测得。

## 3. 已完成的物理升级

新任务与原有 `handover_static/v1`、`handover_static/v2` 隔离，后两者未被修改。物理版本包括：

- 启用重力的 `0.08 kg` 动态杆体；
- 真实刚体碰撞、摩擦和自然掉落；
- 两台独立 Franka、独立绝对 IK 和独立夹爪；
- 四个只过滤物体的指体接触传感器；
- 每步保存末端、四指体、物体、动作、接触力、速度和关系证据；
- 只从物理证据计算的 `none/left_only/both/right_only`，不读取专家 phase；
- 失败时独立重放视频，不污染正式结果；
- 源码与实验参数联合 SHA-256 指纹。

专家不读取 privileged 接触力或关系标签，也没有任何 `write_root_pose_to_sim`、物体速度写入或运动学附着操作。

## 4. 开发集与正式集

| 数据划分 | 成功 | 结果解释 |
|---|---:|---|
| 开发 `7400–7404` | `5/5` | 用于反例修复，不能作为正式成功率 |
| 正式 `7600–7619` | `6/20` | 唯一一次冻结验收，未通过 |

六个正式成功种子为 `7600、7603、7604、7616、7617、7618`。它们全部满足：

- 精确生命周期 `none → left_only → both → right_only → none`；
- `both` 持续 `1.82–1.84 s`，均明显超过 `0.20 s` 门槛；
- 最大物体高度 `0.3042–0.3065 m`；
- 最终 XY 误差 `1.79–2.51 mm`，均明显低于 `40 mm` 门槛；
- 最终物体在桌面上，末段稳定。

这说明：一旦发送臂成功拾取，冻结正式集中观测到的六次样本全部完成了接收、真实共同持物、发送释放、接收单独搬运和物理放置。该条件性结果不能替代总体成功率。

## 5. 失败分类与根因证据

14 个失败全部为 `left_pick_failed`，没有一个正式失败发生在右臂接收或目标放置阶段。失败样本的最大物体高度约为桌面高度 `0.181 m`，说明物体没有被发送臂抬起。

逐指接触轨迹显示两种清晰模式：

- 成功拾取：闭合末端两指力通常约为 `32/29 N`，形成对向夹持；
- 失败拾取：一指接近 `0 N`，另一指达到 `75–103 N`，形成单指侧压，随后机械臂抬升而物体留在桌面。

seed 7602 的失败视频与数值分类一致：夹爪从斜上方接近后，只有一侧指体压住杆体；抬升时夹爪离开，杆体保持在桌面。因而当前首要阻塞不是接收端载荷转移，而是发送端抓点对初始位置和姿态扰动覆盖不足。

初始位置也呈现分布提示，但不能单独作为因果结论：成功样本初始 y 均值为 `0.1943 m`，失败样本为 `0.2045 m`；同时存在 y 较小但仍失败的样本，说明还受到 x、yaw、IK 跟踪误差和指体进场几何的联合影响。

## 6. 关系真值修复的依据

开发 seed 7401 曾在物体仍保持双指接触时产生 0.10 s 的伪断连。审计发现两指力全程约为 `12/10 N`，只是载荷转移导致短时相对位姿沉降。

因此冻结前将关系判据明确分为：

- 建立连接：双指接触、近邻和相对运动一致共同确认；
- 保持连接：双指接触和近邻仍在时保留；
- 相对运动一致性继续进入置信度，但不能单独解除仍有双指接触的连接。

对应回归测试验证了短时沉降不会产生伪断连，而双指接触连续缺失仍会按 3 步迟滞解除连接。正式成功样本均得到无额外跳变的精确生命周期。

## 7. 下一版允许做什么

本报告冻结 v1 结果，不允许在 `7600–7619` 上继续调参并把重跑称为同一正式实验。若继续开发，应建立显式的 v2 过程：

1. 把 v1 失败轨迹仅作为误差分析或新开发集；
2. 让发送抓点和进场路径对物体 yaw 与实际末端误差自适应；
3. 在闭合前验证夹爪是否真正跨过杆体，而不只检查末端中心距离；
4. 用新的开发种子验证双指力对称性和抬升；
5. 冻结新协议后使用完全未见的新正式种子；
6. 只有新正式集满足采集门槛，才创建 `handover_physical/v1` 并进入双臂关系估计/策略阶段。
