# 真实物理双臂交接预注册协议

## 1. 研究目的与冻结边界

本协议只检验 `Essay2608-Bimanual-Physical-Handover-v0` 的脚本专家是否能在真实刚体动力学下完成控制权转移。它不检验学习策略，也不把既有的几何绑定任务当作物理交接证据。

冻结实现为提交 `040ad95`，开发实验记录的源码指纹为：

```text
d77b98611fee1691ff08743e29b0a93557b12ca9d542a5845fa9319e7764b4a2
```

以下内容不允许在查看正式集结果后修改：

- 任务几何、质量、重力、碰撞和摩擦参数；
- 脚本专家状态机、抓点、闭合位和撤离路径；
- 物理关系判据、成功阈值和失败分类；
- 正式种子及输出目录。

现有 `data/handover_static/v1`、`data/handover_static/v2` 与对应旧任务保持不变。正式验收通过前不采集 `data/handover_physical/v1`。

## 2. 物理任务约束

- 物体启用重力，质量为 `0.08 kg`；
- 杆体尺寸为 `0.24 × 0.055 × 0.04 m`；
- 机器人、物体和桌面使用真实碰撞与摩擦；
- 两个 Franka 使用独立 IK 与独立夹爪动作；
- 四个指体分别配置只过滤物体的接触传感器；
- 脚本专家不得读取 privileged 接触力或关系标签；
- 评测过程中不得直接写入物体位姿、速度或运动学 carrier；
- 关系标签只能由双指接触、手物距离和相对运动证据产生，不得由专家 phase 生成。

接收夹爪使用 `0.024 m/指` 的物理任务专用闭合位，以避免把杆体过度挤出；接收抓点位置随物体 yaw 旋转，但腕部姿态不跟随物体旋转。发送臂释放后先沿负 x 方向退出，再向自身基座侧撤离，避免张开的指体扫过交接物。

## 3. 关系真值定义

每条臂—物边独立维护。建立连接要求同时满足：

1. 两个指体均对物体产生不低于 `0.15 N` 的过滤接触力；
2. 末端与物体距离不超过 `0.160 m`；
3. 6 步窗口内相对位置 RMS 不超过 `0.006 m`；
4. 上述证据连续确认 3 步。

连接建立后，只要双指接触和近邻条件仍成立，就保留连接；相对运动一致性仍写入诊断置信度，但载荷转移中的短时沉降不能单独解除一个仍有双指接触的物理连接。双指接触或近邻证据连续缺失 3 步后才解除连接。

期望的压缩关系序列固定为：

```text
none → left_only → both → right_only → none
```

## 4. 数据划分

- 开发种子：`7400–7404`；只用于实现和反例修复，最终冻结结果为 `5/5` 成功；
- 正式未见种子：`7600–7619`，共 20 个；
- 正式输出目录：`outputs/physical_handover/formal_v1`；
- 每个正式种子最多运行 1400 个控制步，控制周期为 `0.02 s`。

正式集只运行一次。若有失败，可在不修改代码和阈值的前提下用同一源码重放失败种子并保存视频；重放结果不替换第一次正式结果。

## 5. 单次成功与批量验收

单次成功必须同时满足：

- 脚本专家完成且环境未提前终止；
- 压缩关系序列与预注册序列完全一致；
- `both` 累计持续时间不低于 `0.20 s`；
- 最终物体与目标 XY 距离小于 `0.04 m`；
- 最终物体高度与桌面目标高度差不超过 `0.025 m`；
- 最后 25 步最大位移不超过 `0.01 m`。

批量结果分两级解释：

- 科学验收线：至少 `18/20` 成功，且失败必须按固定 taxonomy 报告；
- 新物理数据采集门槛：`20/20` 全部成功。未达到时不得创建或宣称冻结 `handover_physical/v1`。

固定失败分类包括：专家自身失败、环境提前结束、关系生命周期不完整、`both` 太短、物体未落在支撑面、末段不稳定和 XY 放置误差超阈值。
