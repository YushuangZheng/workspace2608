## 3. 非选择性采集证据

采集器在临时目录中按固定顺序运行全部 20 个 seed。只有当所有 worker 成功、源码指纹
一致且预审计通过后，临时数据集才原子移动到目标路径。实际结果为：

- 请求 seed：20 个；
- 成功 seed：20 个；
- 失败 seed：0 个；
- 替补 seed：0 个；
- 目标目录提前出现：否；
- 使用 v3 正式评测 seed：否；
- 使用几何 `carrier`：否。

冻结后分别重试采集和冻结，两条命令都在写入前返回非零；manifest、`FROZEN` 和代表性
NPZ 的哈希保持不变。

## 4. schema 与关系来源

每条 NPZ 保存连续的 20 ms 时间轴、专家状态、16D 双臂动作、左右末端与物体 7D 位姿、
目标位姿、物体线速度、四指三维接触力、四指世界位置、左右独立连接状态与置信度、
四值关系标签及终端稳定指标。

关系标签逐步由以下两条独立边组合：

```text
left_connected × right_connected
→ none / left_only / both / right_only
```

连接边来自双指接触、末端—物体近邻和相对运动一致性，不读取专家 `state`。20 条数据中，
物理关系标签与旧的 phase 映射共有 2007 个逐步差异，每条 100–106 步；这提供了标签
并非 phase 直接复制的持久化证据。

  --data_dir data/handover_physical/v1 \

                   8210 8211 8212 8213 8214 8215 8216 8217 8218 8219

审计不启动仿真，也不修改冻结目录。它会重新计算全部文件哈希、数据集哈希、成员关系、
时间/shape/有限值、关系生命周期、双边连接组合、接触一致率、初始覆盖和终端成功指标。

## 7. 使用边界

- 接触与物理关系是 privileged 监督，可用于训练/评估估计器，但不能直接作为部署策略观测；
- 数据只覆盖一个杆体、一个桌面、固定双臂布局和有限初始扰动；
- 所有轨迹来自同一个脚本专家，不包含人为风格或策略多样性；
- 当前数据证明的是数据与监督链路可信，不是 learned policy 成功；
- Phase 5 必须用独立的 receiver miss、delay、giver early release、receiver loss、
  prolonged both 和 paused arm 反例验证在线估计，不能只在这 20 条训练演示上汇报精度。
