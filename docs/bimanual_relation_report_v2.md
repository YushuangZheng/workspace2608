# 双臂在线关系估计正式评测 v2 报告

## 结论

正式 v2 **通过全部预注册门槛**。七类条件与十个未见 seed 共 70 条 trial 均唯一完成：
物理干预成立 `70/70`，预注册推断关系序列精确 `70/70`，逐条准确率、左右 F1、关系转移
延迟和条件特有安全门全部通过。四个要求保持任务成功的条件共 `40/40` 成功。

v1 唯一失败项 `prolonged_both_hold` 从 `7/10` 提升为 `10/10` 物理成立；v2 的十条长双持
均在完整 100 个干预步保持物理和推断 `both`，且 `10/10` 最终完成放置。这证明顺应式
双臂随动保持修复了原来的固定笛卡尔目标冲突，不需要修改关系估计器或放宽阈值。

本结果只通过 **双臂在线关系检测门**。它不等于双臂恢复策略或学习策略已经完成，也不
证明超出当前任务、物体、机器人和预注册干预分布的泛化能力。

特有门，不靠聚合平均值掩盖失败。

## v1 到 v2 的因果修复

v1 的长双持干预把两臂持续拉回进入 transfer 时的固定目标。在三个 seed 中，接收臂承担
载荷后发送端因内部力与沉降真实失去接触。v2 在额外两秒窗口中每步把左右动作目标更新为
各自当前实测末端位姿，只维持闭合夹持和 phase-clock 冻结，从而减少控制器之间的刚性
对抗。

开发 seed 8303–8307 先得到 `5/5`，随后才预注册 v2。正式 seed 8500–8509 得到 `10/10`，
而且未修改：

- 两条在线关系估计器及其标定配置；
- 接触物理真值和条件成立定义；
- 四值准确率、左右 F1 和转移延迟门；
- 脚本专家正常路径、任务成功门和冻结数据集。

v1 与 v2 使用不同未见 seed，不能把 7/10 与 10/10 当成严格配对统计检验；它们支持的是
“预先诊断的动作冲突经单一机制修复后，在独立 cohort 中不再出现”这一受限结论。
