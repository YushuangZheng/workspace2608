## 3. v3 正式划分

- 正式未见种子：`8000–8019`，共 20 个；
- 正式输出目录：`outputs/physical_handover/formal_v3`；
- 每个 seed 最多 1400 个控制步，控制周期 `0.02 s`；
- 正式集在本协议冻结后只运行一次；
- 失败只能用相同源码在独立目录重放视频，不允许覆盖正式 JSON/NPZ。

## 4. 固定单次成功标准

每个 seed 必须同时满足：

- 专家完成且环境未提前终止；
- 压缩关系序列精确等于 `none → left_only → both → right_only → none`；
- `both` 累计持续时间不低于 `0.20 s`；
- 最终物体与目标 XY 距离小于 `0.04 m`；
- 最终高度误差不超过 `0.025 m`；
- 最后 25 步最大位移不超过 `0.01 m`。

不根据正式结果修改阈值或 taxonomy。专家不读取 privileged 接触力、关系标签或未来
状态，不写物体位姿/速度，也不使用运动学 carrier。

## 5. 固定批量门槛

- 结果报告：无论成功数多少，完整保留并报告 20 个 trial；
- 最小科学验收：至少 `18/20`；
- Phase 4 退出、Phase 5 启动与 `handover_physical/v1` 采集：必须 `20/20`。

最后一项采用点评中的严格标准。即使再次得到 `18/20` 或 `19/20`，也只记录结果和失败
证据，不采集新物理数据、不开始双臂关系估计正式阶段。

## 6. 不变的物理与关系约束

- 物体质量 `0.08 kg`，重力开启；
- 杆体尺寸 `0.24 × 0.055 × 0.04 m`；
- 真实刚体碰撞、摩擦和自然掉落；
- 四个指体独立过滤式接触传感；
- 接收闭合位 `0.024 m/指`；
- 关系连接建立要求双指接触、近邻、相对运动一致连续确认；
- 关系连接保持要求双指接触和近邻，连续缺失后解除；
- 关系真值只用于评测，不反馈给脚本专家。
