# 真实物理双臂交接 v2 正式报告

## 1. 结论

冻结后的 `Essay2608-Bimanual-Physical-Handover-v0` v2 在 20 个未见种子上取得
`18/20`，成功率为 `90.0%`，Wilson 95% 区间为 `[69.9%, 97.2%]`。该结果恰好达到
预注册的 `18/20` 科学验收线，但没有达到 `20/20` 的物理演示数据采集门槛。因此：

- 可以声称当前系统在该冻结扰动分布上通过了真实物理交接的最小科学验收；
- 不创建或宣称存在 `data/handover_physical/v1`；
- 不把 18 个成功 rollout 事后挑选为训练数据；
- 暂不开始依赖新物理数据的完整双臂策略训练；
- 不能把 `90.0%` 写成“完全稳定”或“100% 鲁棒”。

两个正式失败都发生在发送臂拾取阶段、接收臂介入之前。条件于发送臂成功拾取，正式集
中进入交接阶段的 18 个样本为 `18/18` 完成接收、共同持物、发送释放、接收单独搬运和
物理放置。这个条件性结果只定位剩余瓶颈，不能替代总体 `18/20`。

## 3. v2 的单一机制修改

v1 的 `LEFT_GRASP` 每一步都根据物体当前位姿重新计算抓取目标。指体首次接触会推动
物体，控制器随后追逐新位置，形成“推开—追逐—继续推开”的正反馈。v1 因而只有
`6/20`，14 个失败全部为 `left_pick_failed`。

v2 只在进入 `LEFT_GRASP` 时冻结一次发送端抓取起点、目标和指令，随后对固定目标完成
下降与闭合，不再追逐接触扰动后的物体。物体质量、重力、摩擦、接收端轨迹、四指接触
传感、关系判据、正式扰动分布和成功标准均保持不变。

冻结前证据仅用于开发：四个 v1 失败种子加一个成功种子的诊断重放为 `5/5`，全新开发
种子 `7700–7709` 为 `10/10`。这些结果没有计入 v2 正式成功率。

## 4. 正式结果

| 指标 | v2 正式结果 |
|---|---:|
| 总体成功率 | `18/20 = 90.0%` |
| Wilson 95% 区间 | `[69.9%, 97.2%]` |
| 精确关系生命周期 | `18/20` |
| 进入交接后的完成率 | `18/18` |
| `both` 持续时间 | `1.82–1.84 s`，均值 `1.824 s` |
| 最大物体高度 | `0.3036–0.3100 m`，均值 `0.3056 m` |
| 成功样本最终 XY 误差 | `0.67–4.37 mm`，均值 `2.56 mm` |
| 成功样本末段稳定 | `18/18` |

18 个成功样本的压缩关系序列全部精确等于：

```text
none → left_only → both → right_only → none
```

其中没有接收失败、共同持物不足、发送释放失败、运输失败或放置失败。`both` 持续时间
全部显著高于 `0.20 s` 门槛，最终 XY 误差全部显著低于 `40 mm` 门槛。

## 5. 两个正式失败

| seed | 固定分类 | 最大高度 | 数值与视频证据 |
|---:|---|---:|---|
| `7800` | `left_pick_failed` | `0.1907 m` | 物体在桌面被推至 x≈`0.624 m`；闭合后两指力仅约 `3.6/3.7 N`，没有形成承载抓取 |
| `7813` | `left_pick_failed` | `0.2933 m` | 物体曾被抬起，但两指载荷明显不对称，随后在 `LEFT_LIFT` 中脱落 |

两个失败的关系序列都是 `none → left_only → none`，没有出现 `both`。seed 7813 的固定
taxonomy 看起来较粗，因为它不是“完全未离桌”，但分类仍忠实于冻结状态机：发送端在
完成拾取验收前丢失物体，故仍属于 `left_pick_failed`，不能事后改标签。

独立失败视频位于：

- `outputs/physical_handover/formal_v2_failure_audit/videos/scripted_physical_handover__seed_7800/physical_handover_seed_7800-step-0.mp4`；
- `outputs/physical_handover/formal_v2_failure_audit/videos/scripted_physical_handover__seed_7813/physical_handover_seed_7813-step-0.mp4`。

这两次审计与正式 JSON 的失败原因、关系序列、最大高度和源码指纹一致。

## 6. 与 v1 的关系

| 版本 | 正式种子 | 成功 | 科学门槛 | 数据门槛 |
|---|---|---:|---|---|
| v1 | `7600–7619` | `6/20` | 未通过 | 未通过 |
| v2 | `7800–7819` | `18/20` | 通过 | 未通过 |

冻结抓点后，正式成功数从 v1 的 6 增加到 v2 的 18，绝对增加 12 个，说明已识别的追逐
正反馈是 v1 的主要失效机制。两版使用不同的预注册未见种子，因此这里是两个独立冻结
cohort 的描述性比较，不是配对检验，也不把差异解释为精确因果效应大小。

v1 报告和结果继续保留，不由 v2 覆盖。论文或汇报中若呈现 v2，必须同时说明 v1 的
失败诊断、v2 的机制修改以及 v2 仍有 2 个发送端拾取失败。

## 7. 当前允许的下一步

当前物理专家已达到最小科学门槛，可作为真实接触与关系生命周期的原理验证基础；但
预注册的数据门槛没有通过，所以当前阶段停在稳定基础设施和失败分析，不扩大到物理
数据训练。后续若继续提升发送端，应另建 v3：

1. 只把 v2 的两个正式失败用于机制诊断，不覆盖 v2 正式结果；
2. 在闭合后加入基于可观测夹爪状态与物体运动的承载确认，不读取接触真值；
3. 对低力推走与抬升后脱落分别设计开发反例；
4. 冻结新协议后使用新的未见种子正式验收；
5. 只有新正式结果达到预先固定的 `20/20`，才采集完整、无事后筛选的
   `handover_physical/v1`。
