# 真实物理双臂交接 v2 预注册协议

## 1. 与 v1 的关系

v1 正式结果 `6/20` 已冻结在 [正式报告](physical_handover_report.md) 中，不被本协议覆盖。v1 的 14 个失败全部是发送端 `left_pick_failed`；逐帧轨迹证明旧控制器在 `LEFT_GRASP` 中持续追踪被接触推动后的物体位置，形成“推开—追逐—继续推开”的正反馈。

v2 只修改这一处机制：进入 `LEFT_GRASP` 时冻结一次抓取目标，随后用固定目标完成下降与闭合。抓取阶段不再追逐因接触而移动的物体。其余物理参数、接收端控制、关系真值和成功标准均沿用 v1。

## 2. 冻结前证据

以下结果只用于开发，不计入 v2 正式成功率：

- v1 诊断样本 `7600、7601、7602、7612、7619`：`5/5`；其中四个是 v1 的拾取失败；
- 全新 v2 开发种子 `7700–7709`：`10/10`；
- 10 个新开发样本均得到精确生命周期；
- `both` 持续 `1.78–1.86 s`；
- 最终 XY 误差 `0.35–13.43 mm`。

v1 的正式种子从本协议开始只属于开发/诊断信息，不能再用作 v2 正式验收。

## 3. v2 正式划分

- 正式未见种子：`7800–7819`，共 20 个；
- 正式输出目录：`outputs/physical_handover/formal_v2`；
- 每个种子最多 1400 个控制步，控制周期 `0.02 s`；
- 正式集在本协议冻结后只运行一次。

如果正式 trial 失败，只允许使用相同提交在独立目录重放视频，不允许修改参数后覆盖或替换正式结果。

## 4. 固定成功标准

单次成功必须同时满足：

- 专家完成且环境未提前终止；
- 压缩关系序列精确等于 `none → left_only → both → right_only → none`；
- `both` 累计持续时间不低于 `0.20 s`；
- 最终物体与目标 XY 距离小于 `0.04 m`；
- 最终高度误差不超过 `0.025 m`；
- 最后 25 步最大位移不超过 `0.01 m`。

批量门槛保持不变：

- 科学验收：至少 `18/20`；
- `handover_physical/v1` 数据采集：必须 `20/20`。

即使达到 `18/20`，只要未达到 `20/20`，仍不采集新物理数据。正式失败继续按固定 taxonomy 报告，不根据结果修改阈值。

## 5. 不变的物理和关系约束

- 物体质量 `0.08 kg`，重力开启；
- 杆体尺寸 `0.24 × 0.055 × 0.04 m`；
- 真实碰撞、摩擦和自然掉落；
- 四个指体独立过滤式接触传感；
- 接收闭合位 `0.024 m/指`；
- 专家不读取 privileged 接触力或关系标签；
- 不写物体位姿、速度，不使用运动学 carrier；
- 连接建立要求双指接触、近邻、相对运动一致连续确认；
- 连接保持要求双指接触和近邻，连续缺失后解除。
