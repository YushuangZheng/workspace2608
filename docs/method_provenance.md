# 方法来源与实现边界

本文区分三类内容：DynaMAC 论文直接支持的方法、受论文启发的简化，以及本项目新增
机制。本地权威来源是未修改的 `DynaMAC.pdf`，论文题为 *One Hand Watches The
Other: Dynamic Multi-Agent Cooperation for Sample-Efficient Bimanual
Manipulation in Dynamic Environments*，作者为 von Hartz、Valada 和 Boedecker。

## 来源映射

| 组件 | 论文方法 | 本仓库实现 | 分类 |
|---|---|---|---|
| 局部流 | 在 `R3 x S3` 上用任务参数参考系表示稠密六维末端位姿，并拟合黎曼高斯边缘分布（Sec. III-A，Eq. 1–2） | 在世界、物体、目标参考系中拟合阶段归一化欧式位置高斯；朝向取自世界模型 | 论文启发的简化 |
| 融合 | 条件独立高斯专家乘积（Eq. 3） | 带旋转三维协方差的平移高斯专家乘积 | 论文启发的简化 |
| 基础学习器 | MiDiGaP 与 TAPAS | 本仓库自写的小型阶段对齐高斯学习器 | 项目实现，不是 MiDiGaP 复现 |
| 技能分段 | TAPAS 自动分段演示（Algorithm 1，第 1 行） | 脚本专家阶段 0–9 作为临时固定技能标签 | 占位简化 |
| 连接统计量 | 技能内六维精度，`M = |det Lambda|^(-1/(2d))`，`d=6`（Eq. 5） | 对正则化欧式位置加旋转向量协方差计算相同的行列式尺度 | 公式忠实，位姿几何简化 |
| 连接过滤 | 移除已连接的动态参考系；短时精度峰可忽略或时间滤波（Sec. III-B、脚注 1） | 某技能至少一半归一化 bin 满足 `M < 0.001` 时，整段移除物体 | 论文启发的固定技能规则 |
| 虚拟参考系 | 每个技能边界捕获静态末端参考系并保留历史（Algorithm 1，第 5 行） | 阶段 `k` 开始时捕获 `virtual_skill_k`，当前技能以前的全部虚拟参考系都作为候选 | 使用简化学习器的结构复现 |
| 任务参数选择 | 每时刻归一化候选精度行列式，取时间最大值并以 `omega` 阈值筛选（Eq. 6） | 对六维协方差使用相同归一化/最大值结构，固定阈值 0.2 | 公式忠实；论文未给阈值，0.2 为预声明项目选择 |
| 执行 | 每个技能拟合一个多流策略并串联执行（Algorithm 1，第 7–8 行） | 阶段时钟控制器为每个人工阶段使用固定参考系集合 | 论文启发的简化 |
| 在线屏蔽 | 论文在策略拟合前从演示技能分布推导连接 | `OnlineDynaMACPrototype` 在运行时滑窗观察物体/末端平移和夹爪状态 | 项目新增原型，不是论文算法 |
| 双向关系 | 论文允许每技能连接开始和结束，但没有定义运行时状态机 | `OnlineRelationEstimator` 使用四个滞回状态、实测指关节、六维相对运动、共同运动相关性和连续置信度 | essay2608 新机制 |
| 夹爪门控与锁存 | 论文主要依据每技能精度推断连接，不把夹爪门控规定为主测试 | 在线旧原型在演示夹爪命令张开时清除，否则锁存；SkillDynaMAC 无运行时门控 | 项目新增且不完整的逻辑 |
| 参考系激活 | 每个已学习技能使用固定任务参数（Algorithm 1） | SkillDynaMAC 使用纯训练阶段选择；在线旧原型依据运行时连接并硬编码阶段 4 切换 | 前者论文启发，后者项目特有 |
| 释放处理 | 每技能分析允许放置后连接结束（Fig. 3） | 旧在线原型锁存到张开命令；`SkillDynaMACPolicy` 只在阶段边界变化 | 项目行为不完整 |
| 双臂化 | 拟合两个并发 DynaMAC，并把对侧末端加入候选任务参数（Sec. III-C） | 现有双臂控制器使用手工协调和载体切换 | 论文启发的工程原型，不是复现 |
| 扰动 | DynaBench 改变有效任务配置并测试平滑/突发动态（Sec. IV） | 自定义 Isaac Lab 任务中使用确定性 8 cm 物体移动、10 cm 目标移动和临时 6 cm 动作偏置 | 受论文启发的项目评测，不是 DynaBench |
| 指标 | 论文在 200 episode 上报告静态/动态任务成功 | 稳定组合放置、XY 灵敏度、旧三维误差、恢复、路径/动作诊断及相对脚本阶段的连接判定 | 项目指标，数值不可与论文等同 |

## 三个名称的不同含义

`SkillDynaMACPolicy` 是论文忠实的简化基线。它按 Algorithm 1 顺序执行：标注技能、
识别连接物体参考系、在每个边界增加虚拟末端参考系、用类似 Eq. (6) 的分数选择
参考系，并执行固定的逐技能策略。它不含在线检测器。

`OnlineDynaMACPrototype` 是早期项目机制。它在线估计仅平移的连接，检测后屏蔽物体
流，并在阶段 4 创建一个虚拟参考系。兼容别名 `DynaMACPolicy` 仍指向该类，保证旧
脚本和旧方法标签可用。因此名为 `full_dynamac` 的结果表示该原型，而非论文完整复现。

`MaskOnlyPolicy` 单独隔离运行时屏蔽，不使用虚拟参考系，是在线项目原型的消融。

## 简化 SkillDynaMAC 的精确流程

流程只读取五条冻结训练演示，不查看评测 seed 或结果。

1. 把脚本专家每个阶段作为临时技能，并重采样为 25 个归一化 bin。
2. 拟合世界、物体、目标和十个虚拟技能高斯流。每个模型同时保存原始三维位置协方差，
   以及“位置 + 四元数切空间旋转向量残差”构成的六维协方差。
3. 对物体流应用 Eq. (5)，`tau_M = 0.001`；某技能至少 50% bin 低于阈值时标记
   物体已连接。目标由任务本体定义为外生，不参与连接候选。
4. 移除已连接物体，加入截至当前技能的全部虚拟参考系，计算类似 Eq. (6) 的归一化
   精度分数，并保留最大分数超过 0.2 的候选。若数值竞争移除全部参考系，则保留分数
   最高者。
5. 执行时在每次阶段转移捕获当前末端位姿，用仓库的平移专家乘积融合所选流；朝向和
   夹爪只使用世界流。

拟合产物 manifest 记录每个候选、Eq. (5) 统计、Eq. (6) 分数、选择和阈值。评测
指纹还记录策略、检测器、阶段时钟、扰动、成功条件、数据、源码和 checkpoint 配置。

## 训练集诊断与已知失败

在五条冻结演示上，Eq. (5) 把阶段 0 和阶段 2–9 的物体都标为连接，仅阶段 1 不连接，
这不是合理物理真值。物体朝向几乎恒定，正则化尺度的旋转方差会压低六维行列式，即使
平移相对运动并非刚性。论文允许加权精度矩阵，但本基线刻意不根据测试表现调权，以便
暴露这种不匹配。

Eq. (6) 还在阶段 5 选择许多历史虚拟参考系。时间最大值会接纳只在一个归一化 bin
占优的参考系，多个近退化协方差又会剧烈竞争。这些选择确定且可检查，但不能解释为
学习到的语义参考系相关性。

六条件仿真冒烟（seed 6200）在静态、物体平滑/突发移动和临时机械臂偏置上成功，
但两个 10 cm 目标移动条件均失败，最终 XY 误差 67.83 mm。静态试验的最终 XY
误差 4.65 mm、旧三维误差 59.18 mm、322 步、末端路径 1.037 m。目标失败与多个
静态虚拟流稀释目标流一致，但这些仍只是工程冒烟，不验证连接标签，也不支持论文级性能。

提交 `c979a94` 的三 seed 干净矩阵包含 90 条唯一试验（五方法 × 六条件 × 三 seed），
每条都有 JSON/NPZ 证据和共同源码/数据指纹。SkillDynaMAC 成功 10/18，合格扰动
恢复 8/15；所有物体移动成功，六个目标移动全失败，seed 6201 另有一次静态和一次
机械臂偏置放置失败。条件平衡平均 XY 误差 25.95 mm，平均路径 1.152 m。

固定逐技能标签与脚本物理连接阶段比较时，平均假阳性比例 0.621、假阴性为零；这是
离线标签诊断，不是在线检测率。Mask-only 和在线原型均为 18/18，World 与 Static
Multi-stream 均为 0/18。三个留出 seed 只能用于诊断，不能作为论文级估计。

## 尚未实现的论文组件

- TAPAS 分段及其学习视觉任务参数；
- MiDiGaP、论文完整黎曼位姿分布和并行协方差传输；
- RGB-D/DINO 感知、杂物拒绝或遮挡测试；
- 论文 RLBench/DynaBench 任务、200 episode 协议和所报基线；
- 经验证的位置/旋转加权矩阵、标定流程或连接检测置信区间；
- 两个并发、论文忠实的双臂 DynaMAC，以及对侧末端候选流。

因此，仓库中的结论必须写为“受论文启发的简化”或“项目新增机制”，不能声称等价于
论文系统。
