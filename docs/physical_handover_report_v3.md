# 真实物理双臂交接 v3 正式报告

## 1. 结论

冻结后的 v3 脚本专家在 20 个全新未见种子上取得 `20/20 = 100%`，Wilson 95% 区间为
`[83.9%, 100%]`。20 个 trial 全部满足预注册的严格成功标准，并全部产生精确关系序列：

```text
none → left_only → both → right_only → none
```

因此 v3 同时通过：

- `18/20` 最小科学验收线；
- `20/20` Phase 4 退出门槛；
- `20/20` 新物理演示数据采集门槛。

该结果允许启动完整批次的 `handover_physical/v1` 数据采集与 Phase 5 双臂关系估计，但
不等于学习策略已经完成，也不证明当前专家在预注册分布之外仍为 100% 鲁棒。

## 3. v3 修复机制

v2 在 20 个正式 seed 上得到 `18/20`。两个失败都来自发送臂拾取，而不是交接后半程。
进一步审计发现，v2 虽然冻结了下降抓点，却仍允许机械臂在桌面上方存在最多 5 cm 的
横向误差时开始下降；长杆因此可能先被手掌或指体从侧面推走。

v3 在不读取接触真值的前提下，只收紧两个可观测几何门：

- 下降前，发送末端必须进入实际 pregrasp command 的 15 mm 范围；
- 闭合前，发送末端必须进入冻结 grasp command 的 15 mm 范围。

这使横向对齐在仍有垂直净空时完成，随后下降近似为垂直运动。物体、摩擦、重力、夹爪
参数、接收端轨迹、关系真值、最终成功门和正式扰动分布均未改变。

最短 `both` 仍为 1.50 s，是预注册 0.20 s 下限的 7.5 倍。最大 XY 误差 11.38 mm，
显著低于 40 mm 门槛。所有物体最终回到支撑面且末段稳定。

## 5. 三版结果的科学边界

| 版本 | 正式种子 | 结果 | 关键变化 |
|---|---|---:|---|
| v1 | `7600–7619` | `6/20` | 原始物理专家；下降中追逐被推动物体 |
| v2 | `7800–7819` | `18/20` | 冻结下降抓点 |
| v3 | `8000–8019` | `20/20` | 在净空高度完成 15 mm 对齐后再下降 |

三个版本使用不同的冻结未见种子，属于连续机制修复后的独立 cohort，不是同一 seed 上的
配对统计。可以陈述“在相同扰动定义和成功标准下，连续冻结版本从 6/20 提升到 18/20，
再到 20/20”，但不能把跨 cohort 差异解释为精确的配对因果效应。

`20/20` 也不是无限总体上的确定成功率；Wilson 区间的下界为 83.9%。论文中必须同时
报告样本量、扰动范围、区间估计和前两版失败历史。

## 6. 数据采集边界

v3 通过门槛后，允许创建 `data/handover_physical/v1`，但必须遵守：

1. 先冻结独立的数据协议、seed 和 schema；
2. 采集完整预注册批次，不从正式成功轨迹事后挑选；
3. 数据关系标签继续由物理接触和相对运动产生，不读取专家 phase；
4. 每个样本保留动作、双臂末端、物体、四指接触、独立置信度和关系生命周期；
5. 采集完成后生成逐文件 SHA-256、manifest 和不可覆盖标记；
6. 只有数据审计通过后，才将它用于 Phase 5/6。
