# 开发阶段评测归档

这里保存技术路线开发期间各阶段最终保留的验证工具和结果：

- `phase23_component_ab/`：关系—进度推断与动态角色的组件 A/B；
- `phase4_boundary_readiness/`、`phase4_boundary_calibration/`、`phase4_transaction_integration/`：边界就绪、参数标定与事务集成；
- `peer_execution_dependency/`：对侧机械臂执行依赖筛选；
- `phase5_recovery_acceptance/`、`phase5_behavior_ab/`：恢复元数据和恢复行为验收；
- `phase6_rlbench_integration/`：RLBench 集成诊断；
- `phase6_formal_evaluation/`：阶段六冻结协议、调度与最终开发验收结果。

这些内容用于追溯技术路线的开发与验收。后续论文实验应在 `evaluations/` 下另建目录。
