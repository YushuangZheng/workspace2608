# Evaluations

The maintained evaluation suite is under `iclr2027/`. It contains controlled
protocols, manifests, runners, physical-event auditing, deterministic analysis,
and native-system interfaces.

Start with [`iclr2027/README.md`](iclr2027/README.md) for the experiment layout
and reproducibility commands. Full rollout records and simulator assets are
optional runtime artifacts and are not required by the source package.
